## Architecture

- Preview imports the exact TSX component and `threeui.css`. Do not recreate shaders, canvas setup, or motion.
- Play Circle is the TSX `variant="play"` transform of the canonical HTML (circle geometry, play glyph, `--h:88px`, `playStrokeWidth`, `liquidMetalPlayButton` postMessage). Canonical HTML stays unmodified.
- Gallery well CSS (`--lmp-play`) is separate from authored source.
- Snippets: play-transformed HTML / iframe React with inlined play HTML / Express serving that HTML. Generated by `plans/liquid-metal-play-gen.js`.
- Append after the current final tray (`dot-border`). Do not reorder earlier trays.
- Color exception: authored colored liquid-metal finish.
